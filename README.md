# Pikazord - Official Website

Welcome to the official repository of Pikazord’s company website. Pikazord specializes in delivering innovative web development and automation solutions tailored to client needs. This repository contains the source code for our website built with modern web technologies.

## 🛠 Technologies Used

- **Next.js**: A React framework for server-side rendering and static site generation.
- **Tailwind CSS**: A utility-first CSS framework for designing responsive and modern user interfaces.
- **Node.js**: For backend functionality and API integrations.
- **Vercel**: Hosting platform for deployment.
